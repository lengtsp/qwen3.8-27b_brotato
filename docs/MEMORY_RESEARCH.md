# Visual and episodic memory research

See [Research mapping](RESEARCH.md) for primary papers and implementation status, and [Experiments](EXPERIMENTS.md) for the controlled-comparison design.

Short visual memory preserves timestamped association hypotheses. Episodic memory stores observed actions and outcomes. Procedural drafts propose context-dependent behavior. They must remain distinct so a remembered coordinate or speculative cause cannot authorize native input.

The current exploratory trial does not establish improved vision accuracy or collection. Playback/replay tests can check implementation invariants; they cannot prove an action would have collected more objects in a different live trajectory. Memory advice remains bounded, with source/geometry checks owned by the controller. Candidate lessons are not automatically promoted.
