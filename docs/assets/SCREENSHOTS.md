# Public visual examples

- `control-room-live.png`: one reviewed archived Control Room screenshot from an earlier version. It illustrates a selected game window, overlays and decision logs. It is not a benchmark dataset, current UI specification or proof of improved gameplay.
- `workflow-research.png`: AI-generated conceptual workflow using abstract original symbols, made with the built-in image generation tool on 2026-10-23. No game reference image was supplied. See `workflow-prompt.txt` for the full prompt.

- `system-architecture.png`: a conceptual deployment/control-flow view, created with the built-in image tool and corrected for capture arrow direction. See `system-architecture-prompt.txt`.
- `memory-evaluation-system.png`: a conceptual view separating local retrieval/review from untested candidates and proposed held-out evaluation. The baseline preserves visual tracking while disabling episodic advice. See `memory-evaluation-prompt.txt`.

Detailed calibration frames, sprite/icon catalogs, terminal-screen collections and raw desktop captures are not distributed in this edition. Game artwork in the archived screenshot retains its original rights.
