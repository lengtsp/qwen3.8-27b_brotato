# Route continuity, GPU assessment and resource measurements

The privately maintained prototype includes eight-direction movement, retained pickup intent, bounded relative projectile forecasts and asynchronous GPU proposal handling. The public materials describe these mechanisms, not evidence of better live collection.

CPU evidence remains below 500 ms; executable GPU arrows below 400 ms; initial same-wave scene-context review below 1,500 ms has no direction authority. Native key ownership expires after 250 ms. Planning a longer route cannot extend those deadlines.

Measure CPU perception/planning, GPU inference, source-to-dispatch/ACK and verified motion separately. Acknowledgement is not measured displacement. Private memory, working set and VRAM are different resource measurements; the UI's alerts do not cap the game's allocation.

[Benchmark methodology](EXPERIMENTS.md) defines the comparisons and limits. Detailed game resources and raw traces are private and excluded from this public tree.
