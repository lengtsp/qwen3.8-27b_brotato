# Original explanatory figure

[Research overview PNG](assets/research-overview.png) is an original AI-generated infographic, visually checked against the selected measurements. It contains no commercial game screenshots, artwork, item/weapon sprites, logos or wiki images.

The only arena picture is a generic rectangle/dot/arrow schematic. The figure illustrates asynchronous component interfaces: current screenshots independently feed CPU, Qwen and selected-image memory work; historical memory is advice for the model; current-image CPU checks precede native keyboard action. Human menus remain a separate responsibility.

The CPU replay, embedding service and image-corpus measurements came from separate experiments. The graphic is not an end-to-end benchmark, a research-paper figure reproduction, or evidence of autonomous completion. The memory-to-model interface has software checks; the reported non-gameplay memory probe had no live advice-consumption measurement.

Created with OpenAI's built-in image generation tool. The brief requested a bilingual research poster with exact measured labels, CPU/GPU/Memory roles and explicit limitations, while excluding all game assets. Connector edits ensured independent current-image input to Qwen and advisory-only memory.
