หลายคนคงเคยเห็น AI สร้างเกมกันแล้ว คราวนี้ลองให้ AI เล่นเกมให้ด้วยซะเลย 🎮🤖

ผมกำลังพัฒนา AI agent ควบคุม Brotato จากภาพหน้าจอ ให้เดินเก็บของ หลบอันตราย และรักษา HP พร้อมแสดงเส้นทางกับ log ใน Control Room

ใช้ Qwen ผ่าน vLLM + Simple-JEV ประเมินฉากและตัวเลือกการเดิน คู่กับ CPU ที่ตรวจภาพล่าสุดและส่งปุ่ม จึงไม่ต้องรอคำตอบโมเดลใหม่ทุกปุ่ม

เทคนิคหลักคือรักษาเป้าหมายเก็บของ เตรียมแผนหลัก/สำรอง ติดตามวัตถุข้ามเฟรม คาดแนวกระสุน และเดิน 8 ทิศทาง ส่วน memory ใช้ค้นประสบการณ์และร่างบทเรียน ยังไม่ fine-tune Qwen และยังไม่ยืนยันว่า memory ช่วยให้เล่นดีขึ้น

ผลด้านความเร็ว: นำภาพเกมที่บันทึกไว้มาทดสอบซ้ำแบบออฟไลน์ หลังปรับโค้ด เวลามัธยฐานต่อขั้นของงาน CPU ลดจาก 123.20 เหลือ 78.52 ms หรือประมาณ 36% หมายถึงขั้นตอนบน CPU เร็วขึ้นในชุดทดสอบเดิม ส่วนความเร็ว Qwen และผลการเก็บของ/รักษา HP ในเกมจริงต้องวัดแยก

ยอด token ที่ตรวจสอบได้จาก 16 ช่วงการควบคุม รวม 3,034,643 tokens (input + output) นับคำตอบโมเดลแต่ละครั้งเพียงครั้งเดียว แม้นำไปใช้เดินหลายครั้ง ยอดนี้ยังไม่ครอบคลุมทุกคำขอหรือการเล่นทั้งหมด

ตอนเลือกตัวละคร อาวุธ ความยาก Level up, Shop และไอเท็ม ยังให้คนตัดสินใจผ่าน human in the loop

แนวคิดประกอบจาก VideoAgent, JARVIS-1, Reflexion, Voyager และ AgentGarten โดยปรับใช้บางส่วน
