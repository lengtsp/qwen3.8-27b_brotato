หลายคนคงเคยเห็น AI สร้างเกมกันแล้ว คราวนี้ลองให้ AI เล่นเกมให้ด้วยซะเลย 🎮🤖

ผมกำลังพัฒนา AI agent ควบคุม Brotato จากภาพหน้าจอจริง ให้เดินเก็บของ หลบอันตราย และรักษา HP พร้อมแสดงเส้นทางกับ log ใน Control Room

ใช้ Qwen ผ่าน vLLM + Simple-JEV ประเมินฉากและตัวเลือกการเคลื่อนไหว ทำงานคู่กับวงจร CPU ที่ตรวจภาพล่าสุดและส่งปุ่ม โดยไม่ต้องรอคำตอบโมเดลใหม่ทุกปุ่ม

เทคนิคหลักคือรักษาเป้าหมายเก็บของ เตรียมแผนหลัก/สำรอง ติดตามวัตถุข้ามเฟรม คาดแนวกระสุน และเดินได้ 8 ทิศทาง ส่วน memory ใช้ค้นประสบการณ์และร่างบทเรียนไว้ทดสอบ โดยยังไม่ fine-tune Qwen

ผลทดสอบ replay ออฟไลน์เดิมพบว่าเวลางาน CPU มัธยฐานลดจาก 123.20 เป็น 78.52 ms หรือประมาณ 36% ตัวเลขนี้เป็นผลของ pipeline CPU ไม่ใช่ความเร็ว Qwen หรือคะแนนเกมที่เพิ่มขึ้น ส่วนประโยชน์ของ memory ต่อการเล่นยังต้องพิสูจน์ต่อ

ตอนเลือกตัวละคร อาวุธ Level up, Shop และไอเท็ม ยังมี human in the loop คอยตัดสินใจ

แนวคิดประกอบจาก VideoAgent, JARVIS-1, Reflexion, Voyager และ AgentGarten โดยปรับใช้บางส่วน ไม่ได้จำลองงานต้นฉบับทั้งหมด
