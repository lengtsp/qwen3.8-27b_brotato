หลายคนคงเคยเห็น AI สร้างเกมกันแล้ว คราวนี้ลองให้ AI เล่นเกมให้ด้วยซะเลย 🎮🤖

ผมกำลังพัฒนา AI agent ควบคุม Brotato จากภาพหน้าจอ ให้เก็บของ หลบอันตราย รักษา HP และแสดงเส้นทาง/log ใน Control Room

แบ่งหน้าที่ CPU / GPU:
• CPU อ่านภาพ/HUD หาตำแหน่ง วางทาง ตรวจอายุภาพ/ความเสี่ยง ส่งปุ่ม เก็บ memory/log และเตรียมคำถาม/แปลงคะแนนผ่าน Simple-JEV
• GPU รัน Qwen ผ่าน vLLM ประเมินฉากและให้คะแนนทิศเดิน

CPU ตรวจภาพล่าสุดก่อนใช้คำแนะนำ GPU และเดินต่อได้ระหว่างรอโมเดล จึงไม่ต้องรอคำตอบใหม่ทุกปุ่ม

เทคนิคคือรักษาเป้าเก็บของ มีแผนหลัก/สำรอง ติดตามวัตถุข้ามเฟรม คาดแนวกระสุน และเดิน 8 ทิศทาง ส่วน memory เก็บ/ค้นประสบการณ์บน CPU ใช้ Qwen บน GPU ร่างบทเรียน ยังไม่ fine-tune และยังไม่ยืนยันผลดีต่อการเล่น

ผลด้านความเร็ว: ทดสอบซ้ำด้วยภาพเกมเดิมแบบออฟไลน์ หลังปรับโค้ด เวลามัธยฐานต่อขั้นของงาน CPU ลดจาก 123.20 เหลือ 78.52 ms หรือประมาณ 36% ผลนี้วัดความเร็วงาน CPU ในชุดทดสอบเดิม ส่วนความเร็ว Qwen และผลเก็บของ/รักษา HP ในเกมจริงต้องวัดแยก

ยอดที่ตรวจสอบได้จาก 16 ช่วงการควบคุม รวม 3,034,643 tokens (input + output) นับคำตอบโมเดลแต่ละครั้งเพียงครั้งเดียว แม้ใช้เดินหลายครั้ง ยอดนี้ยังไม่ครอบคลุมการเล่นทั้งหมด

เลือกตัวละคร อาวุธ ความยาก Level up, Shop และไอเท็ม ให้คนตัดสินใจผ่าน human in the loop
